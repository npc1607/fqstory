# 🍅 fqstory - 番茄小说终端摸鱼阅读器

基于 **Go + Charm (Bubble Tea / Lipgloss / Bubbles)** 构建的高性能终端番茄小说阅读器。专为职场摸鱼优化，具备多种专业级伪装模式与一键老板键避险机制。

---

## ✨ 摸鱼四大杀手级特性

1. **微服务日志流伪装（Log Stream Mode —— 摸鱼王牌）**：
   按 `m` 键将小说文本实时伪装为后端 Spring Boot / Go slog 规范日志（`[INFO ] [worker-pool-04] c.b.s.OrderWorker - ...`），更支持按 `a` 键开启**伪自动滚屏**（双手离开键盘，终端自动像跑服务一样慢慢刷新输出）。
2. **源码注释伪装（Code Comment Mode）**：
   按 `m` 键将小说段落无缝嵌入到高仿 Go 业务代码的 `//` 注释与 docstring 内。
3. **极简单行模式（Status Line Mode）**：
   只占用终端最底部 1 行，屏幕其余部分完全是假的开发/测试输出。
4. **0.1 秒极速老板键（Boss Key）**：
   在阅读器任意时刻按下 `b` 或 `Esc`，秒级清屏并全屏切换为高仿 `go test -v ./...` 持续测试流；敲击任意按键静默返回当前阅读进度，零状态丢失。
5. **本地 SQLite 离线缓存 + 静默预读**：
   翻到当前章时自动在后台静默预读后 5 章并持久化，翻页毫秒级响应，断网无感，且避免高频触发公司网络审计。

## 🚀 快速启动

### 1. 运行交互式 TUI 书架模式
```bash
go run ./cmd/fqstory
```

### 2. 启动并直接打开/加入某本小说
```bash
# 通过书籍 ID
go run ./cmd/fqstory -book 6883748331202284558

# 通过 PC 网页链接
go run ./cmd/fqstory -book "https://fanqienovel.com/page/7307273223832355390"
```

### 3. 非交互式命令行极速预览
```bash
go run ./cmd/fqstory -book 7307273223832355390 -preview 1
```

## ⌨️ 快捷键指南

| 场景 | 按键 | 功能说明 |
| :--- | :--- | :--- |
| **书架** | `j` / `k` 或 `↑` / `↓` | 上下选择书籍 |
| | `Enter` | 进入选定书籍（自动恢复上次阅读章节及偏移） |
| | `r` | **浏览热门排行榜**（分类榜单浏览与一键入库） |
| | `L` | **账号登录 / 退出登录**（支持扫码或粘贴 Cookie，解锁 VIP 会员全章节） |
| | `i` | **查看书籍详情**（完整简介、分类标签、总字数与阅读百分比） |
| | `a` 或 `/` | 弹出输入框添加新书（支持纯 ID / 网页链接 / 分享文案） |
| | `d` | 移出书架并清理本地缓存 |
| | `q` | 退出程序 |
| **登录面板** | `手机扫码` | 打开【抖音 APP】或【番茄小说 APP】扫描终端二维码并确认 |
| | `c` | 切换为【粘贴 Cookie 登录】模式（支持 `Ctrl+V`） |
| | `s` | 切换回【扫码登录】模式或刷新二维码 |
| | `Esc` | 取消返回书架 |
| **排行榜** | `Tab` / `←` / `→` | **切换榜单分类**（热门总榜/玄幻/仙侠/都市/科幻/女频言情等） |
| | `j` / `k` 或 `↑` / `↓` | 浏览榜单内的小说 |
| | `Enter` | **一键加入书架并立即开始阅读** |
| | `a` | 一键加入书架（保留在榜单可继续挑选） |
| | `i` | 展开选中榜单小说的简介卡片 |
| | `Esc` 或 `q` | 返回书架 |
| **添加书籍** | `Ctrl+V` | **一键读取系统剪贴板**直接粘贴小说链接或ID |
| | `Enter` | 确认提交解析 |
| | `Esc` | 取消返回书架 |
| **阅读器** | `j` / `k` 或 `↑` / `↓` | 单行平滑滚动 |
| | `d` / `u` | 下翻半屏 / 上翻半屏 |
| | `Space` | 整页翻屏（**单行模式下为前进下一句**） |
| | `m` | **循环切换摸鱼模式**（经典极简 ➔ 日志流 ➔ 源码注释 ➔ 单行状态栏） |
| | `c` | **切换伪装背景**（Go Test ➔ Git Status ➔ Docker PS ➔ Htop） |
| | `a` | **开关假日志自动滚屏**（无需手部动作） |
| | `n` / `p` | 下一章 / 上一章 |
| | `t` | 呼出全书章节目录（TOC） |
| | `Shift+D` | **批量离线缓存**接下来 20 章到本地 SQLite |
| | `b` 或 `Esc` | **老板键急救！**瞬间全屏伪装成编译/测试输出 |
| | `q` | 保存当前段落偏移量并返回书架 |
| **单行摸鱼** | `→` / `l` / `Space` | 向前滑动阅读窗口（步进 25 字符） |
| | `←` / `h` | 向后回退阅读窗口 |
| | `c` | 实时切换上半部分高仿工作背景 |
| **老板键屏** | **任意按键** | 静默返回当前阅读小说位置，无缝恢复 |
| **目录** | `/` | **实时关键字/序号过滤搜索**（如搜“第100章”或“剑仙”） |
| | `j` / `k` / `g` / `G` | 上下滚动、顶部/底部直达 |
| | `Enter` | 选定章节跳转阅读 |
| | `Esc` 或 `q` | 返回阅读器或书架 |

## 🏛️ 项目工程结构

```text
fqstory/
├── cmd/
│   └── fqstory/
│       └── main.go              # CLI 入口（交互 TUI 与命令行预览模式）
├── internal/
│   ├── crawler/                 # 番茄小说解析引擎
│   │   ├── client.go            # 落地页网关、全量目录、PC Reader 请求调度
│   │   ├── fontmap.go           # 362 个 PUA 字符映射表与线性解密器
│   │   ├── parser.go            # 纯 ID、网页链接与短链跟随解析
│   │   └── types.go             # 核心数据模型 (BookMetadata / Chapter / Content)
│   ├── masquerade/              # 摸鱼伪装引擎
│   │   └── masquerade.go        # 微服务日志格式化器、代码注释生成器、假系统输出
│   ├── storage/                 # 本地持久化层 (SQLite 纯 Go 实现)
│   │   └── storage.go           # 书架管理、段落偏移量进度记录、章节离线缓存
│   └── ui/                      # 基于 Charm Bubble Tea 的 TUI 表现层
│       ├── model.go             # 全局状态机调度 (Shelf / Reader / Toc / Boss)
│       ├── styles.go            # Lipgloss 暗色低对比度微光主题
│       └── msg.go               # 异步消息定义
├── docs/                        # 交互与架构 Excalidraw 原生图表
│   ├── fqstory-interaction.png  # 交互状态流转图
│   └── fqstory-architecture.png # 系统技术架构图
└── go.mod
```
